🗄️ Data Migration

One-time tool to migrate static gallery pages into Firestore so they can be managed from the dashboard.

⚠️ Run each migration only once. The tool checks for existing data and skips if already migrated.

📚 Kinder 2 — gallery.html

Migrates all Q1–Q4 + Graduation images and captions from the static Kinder 2 gallery into Firestore. After migration, gallery.html will redirect to the dynamic gallery page.

📗 Grade 1 — grade-one.html

Migrates all Q1–Q4 images, sections, and captions from the static Grade 1 gallery into Firestore. After migration, grade-one.html will redirect to the dynamic gallery page.
